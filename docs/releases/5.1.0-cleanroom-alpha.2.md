# Powah Legacy 5.1.0 — Cleanroom Alpha 2

面向 **Minecraft 1.12.2 / Cleanroom 0.4.0 正式版（不带 -alpha）/ Java 25**。此移植保持 Alpha。

## 安装

安装 `powah-legacy-5.1.0-cleanroom-alpha.2.jar`，替换本项目旧 JAR。`-sources.jar` 供开发使用，`SHA256SUMS` 用于校验。

核心玩法只需 Cleanroom。教程可选安装 [Ponder Legacy 1.4.0-cleanroom-alpha.1](https://github.com/mcyudream/ponder-legacy/releases/tag/v1.4.0-cleanroom-alpha.1) 和 **CraftTweaker 4.1.20.698**，均为独立运行包。

加载器 ID 为 `powah-legacy`，物品 / 方块及资源命名空间保留 `powah`。无需另装 Lollipop 或现代 GuideME。

## 内容与改动

- 七等级 FE 发电、储能、线缆及充能球 / 充能棒，包含 36 部件反应堆、末影能源网络和玩家充电设备。
- 107 个方块、38 个独立物品、156 个工作台配方和 14 个充能配方。
- 上游原始机器 GUI 贴图、槽位与仪表坐标回迁，配置按钮和流体交互可操作。
- 按上游 GuideME 21.1.7 布局与素材回迁 28 篇双语手册，支持搜索、历史、插图、配方和 GUI 缩放。
- 553 个英文 / 简体中文语言键；五类可选 Ponder 教程，可从物品或手册进入。
- 正式 CR 0.4.0 专服 Kirino 发现兼容修复；统一包元数据中的正式基线和 Ponder Legacy ID。
- 修复重新进入存档后，Ponder 结构缓存沿用退出期间缺失方块状态的问题。
- 增加 GitHub 标签发行、生产包隔离和安装包哈希验收检查。

## 验收

2 项单元测试通过，双语资源检查通过。正式 CR 0.4.0 上，有 / 无 Ponder 的客户端各 218 条检查、专服各 8 条检查通过。最终包摘要与四组准确运行环境见 [安装包验收](https://github.com/mcyudream/powah-legacy/blob/v5.1.0-cleanroom-alpha.2/LEGACY-VERIFICATION.md)。发布 CI 强制核对生产 JAR 的 SHA-256。

## 当前范围

充能配方的专用 JEI 分类、Curios、EMI 和现代 GuideME 扩展 API 未回迁。长期高负载网络、大型整合包和远程多人联机未作全面组合测试。详见 [README](https://github.com/mcyudream/powah-legacy/blob/v5.1.0-cleanroom-alpha.2/README.md)。
